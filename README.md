В этом репозитории собраны мои проекты по обработке геоданных с использованием Python.  
Основной фокус — автоматизация рутинных задач, работа с геометрией и подготовка данных для дальнейшего анализа и использования.

Проекты

1. Геообработка и ETL-пайплайн (`geodata_ETL.py`)

Скрипт для автоматизации подготовки геоданных.

Что реализовано:
- объединение векторного слоя с табличными данными (CSV) по ключевому полю  
- перенос и расширение атрибутивной информации  
- проверка корректности геометрии  
- автоматическое исправление ошибок  
- очистка атрибутивной таблицы  
- экспорт результата в GeoPackage  

Результат — валидный и подготовленный слой, готовый к использованию в анализе и визуализации.

2. Удаление артефактов при перепроецировании с помощью разреза по 180 меридиану (`cut_poly_m180.py`)

Скрипт для работы с полигональными данными и геометрией.

Что реализовано:
- репроекция полигонального слоя из конической проекции в Pseudo-Mercator
- создание «шва» для корректной обработки разрывов на границе проекции
- разрезание полигона по буферу и обработка мультиполигонов
- сохранение атрибутивной информации без FID-конфликтов
- экспорт финального слоя с корректной геометрией в проект QGIS

Результат — корректно репроецированные полигоны с удалёнными артефактами, разделёнными частями и сохранённой атрибутивной информацией.

О репозитории

Эти проекты я делала, чтобы:
- автоматизировать обработку геоданных  
- сократить количество ручной работы  
- улучшить качество данных  

Скрипты запускаются через Python Console в QGIS.

В результате выполнения скриптов получаются:
- геоданные с валидной геометрией  
- очищенная и структурированная атрибутивная информация
- готовые к использованию слои в формате GeoPackage
